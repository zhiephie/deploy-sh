# DEPLOYMENT SCRIPT

## Deploy
### Contoh Penggunaan:

#### Deploy hari ini:
```bash
./deploy.sh
```

#### Deploy tanggal tertentu:
```bash
./deploy.sh 14042025
```

#### Dry-run untuk hari ini:
```bash
./deploy.sh --dry-run
```

#### Dry-run untuk tanggal tertentu:
```bash
./deploy.sh 14042025 --dry-run
```

## Rollback
### Contoh Penggunaan:

#### Rollback hari ini:
```bash
./rollback.sh
```

#### Rollback tanggal tertentu:
```bash
./rollback.sh 2023.05.12
```

#### Dry-run untuk hari ini:
```bash
./rollback.sh --dry-run
```

#### Dry-run untuk tanggal tertentu:
```bash
./rollback.sh 2023.05.12 --dry-run
```
